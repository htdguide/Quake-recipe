# Glossary

Terms the twins use without re-explaining. Where a term has a name in the source that differs from the plain-words name used in the
recipe, both are given — the source's spelling is in parentheses, because a reader consulting the code will need it.

---

## The world

**Map** — the compiled level: geometry, collision, visibility and baked lighting in one file
([`bspfile.h`](WinQuake/bspfile.h.md)). Produced by a separate compiler the recipe treats as a **given**.

**Binary space partition tree** — the map's spatial structure: each interior node holds a plane and two children, each leaf a convex
region. Used for rendering order, for visibility, and — in a separate, coarser form — for collision.

**Leaf** — a convex region of the map. The unit of visibility: the map records, per leaf, which other leaves can be seen from it. An
entity records which leaves its bounding box overlaps, and that list decides whether it is visible to a given viewer
([`world.c`](WinQuake/world.c.md), [`sv_ents.c`](QW/server/sv_ents.c.md)).

**Visible set** (*PVS*, potentially visible set) — for a leaf, the set of leaves that can possibly be seen from it, computed by the map
compiler and stored run-length encoded. A conservative over-estimate: everything visible is in it, and some things in it are not visible.

**Hearable set** (*PHS*, potentially hearable set) — one step of transitive closure over the visible set: if you can see leaf B and B can
see C, then C is hearable from you. Precomputed by the server
([`sv_init.c`](QW/server/sv_init.c.md)) and used to decide who receives a sound, because sound reaches around a corner and light does not.

**Hull** — a tree of clipping planes used for collision. The map contains **three precompiled hulls**, one per body size, plus a
point-sized one the loader fabricates ([`model.c`](WinQuake/model.c.md)). The body sizes are hard-coded in the engine and are an unwritten
contract with the map compiler.

**Surface** (*face*) — one polygon of the world, with a plane, a texture, texture axes, and up to four layers of baked lighting.

**Lightmap** — baked lighting samples on a sixteen-unit grid across a surface, up to four layers, each layer scaled at run time by its
light style's current level.

**Light style** — a named intensity pattern, a string of letters read as levels, advanced ten times a second
([`r_light.c`](WinQuake/r_light.c.md)). Changing a style's string is how game logic makes static lighting flicker or switch
([`misc.qc`](qw-qc/misc.qc.md)).

**Dynamic light** — a run-time light with a position, radius and lifetime, added into the lighting of whichever surfaces it touches and
invalidating their cached or packed copies.

**Submodel / brush model** — a piece of the map that moves as an entity: a door, a platform, a lift. It has its own hulls and its own
origin.

## Rendering

**Span** — a horizontal run of pixels on one scanline belonging to one surface. The software renderer's unit of work.

**Edge list** — the sorted list of surface edges crossing the current scanline. The software renderer sorts edges rather than pixels,
which is why **the world needs no depth buffer and is drawn with no overdraw** ([`r_edge.c`](WinQuake/r_edge.c.md)).

**Surface cache** — the software renderer's store of lit, mipped copies of world surfaces, allocated by a rover through a ring, and
invalidated when a light style level, a dynamic light set or a texture animation frame changes
([`r_surf.c`](WinQuake/r_surf.c.md), [`d_surf.c`](WinQuake/d_surf.c.md)). Thrashing is detected and reported to the player.

**Lightmap page** — the hardware renderer's replacement for the surface cache: a few large textures into which every surface's lightmap is
packed once at load by a skyline allocator, patched in place when a light changes
([`gl_rsurf.c`](WinQuake/gl_rsurf.c.md)).

**Skyline allocator** — the packing algorithm used for the lightmap pages and the interface-image sheets: remember, per column, how much
height is consumed, and place a rectangle at the lowest position where its whole width fits.

**Mip level** — a halved copy of a texture, used at distance. Generated by a box filter; point sampling shimmers.

**Palette index** — a byte naming a colour in the game's 256-entry palette. The software renderer's framebuffer is one of these per pixel,
which makes brightness effects — damage flashes, gamma, liquid tints — a 256-entry reprogram rather than a per-pixel operation
([`vid_dos.c`](WinQuake/vid_dos.c.md)).

**Colour translation** (*colormap*) — a 256-entry remap applied to a player's skin so that two reserved palette ranges take the colours
that player chose ([`gl_rmisc.c`](WinQuake/gl_rmisc.c.md)).

**Animated model** (*alias model*) — a character or item model: one topology, many poses, with vertex normals **quantized to 162
directions** so that per-vertex lighting is a table lookup ([`modelgen.h`](WinQuake/modelgen.h.md)).

**Sprite** — a flat image drawn as a quad, with one of four orientation rules: facing the viewer, facing the viewer but upright, oriented
by its own angles, or about a fixed axis ([`spritegn.h`](WinQuake/spritegn.h.md)).

**Particle** — a single coloured point with a velocity and a lifetime, drawn as a square in software and a textured quad in hardware.

**Temporary entity** — a short-lived visual effect with no entity behind it: an explosion, a lightning beam, a spark. Sent as a kind plus
a position and expanded entirely by the client ([`cl_tent.c`](WinQuake/cl_tent.c.md)).

**Dirty rectangle** — the region of the screen that changed, tracked so the software renderer presents only that. The hardware renderer
presents whole frames and drops the concept ([`gl_screen.c`](WinQuake/gl_screen.c.md)).

## Simulation

**Entity** (*edict*) — a variable-sized record with the engine's own fields in front and the game logic's fields behind, addressed by byte
offset ([`progs.h`](WinQuake/progs.h.md)). An entity's slot number is also its network identity.

**Movement type** (*movetype*) — how the engine simulates an entity: not at all, walking, flying, tossing, bouncing, stepping, or pushing
others ([`sv_phys.c`](WinQuake/sv_phys.c.md)).

**Solidity** (*solid*) — how an entity collides: not at all, as a trigger, as a box, as a slide box, or as a brush model.

**Slide move** — moving along a velocity and, on each impact, clipping the velocity into the surface and continuing. Two surfaces leave
only their crease to slide along; three stop the mover.

**Minkowski reduction** — turning a box sweep into a point sweep by expanding the obstacle by the mover's size. The engine's whole
collision model rests on it ([`world.c`](WinQuake/world.c.md)).

**Trigger** — an invisible volume with a touch handler. The unit of level logic ([`triggers.qc`](qw-qc/triggers.qc.md)).

**Target and name** (*target* / *targetname*) — the map's wiring: an entity names what it activates by string, resolved by searching the
entity list at fire time ([`subs.qc`](qw-qc/subs.qc.md)). Late binding is the map format's whole extensibility.

**Spawn flag** — a bit on a map entity that selects a variant of its behaviour. The other half of the map format's extensibility
([`doors.qc`](qw-qc/doors.qc.md)).

**Think time** (*nextthink*) — an entity's single timer. Because there is only one, animation and behaviour are the same mechanism and a
delayed action must become a spawned entity.

**Game logic** (*progs*) — the compiled program the server runs for all game rules
([`qw-qc/`](qw-qc/README.md)), executed by a 62-operation interpreter over a flat slot pool
([`pr_exec.c`](WinQuake/pr_exec.c.md)).

**Engine operation** (*builtin*) — one of the numbered functions the game logic may call. The numbering is compiled into the game logic and
is therefore **append-only forever** ([`pr_cmds.c`](WinQuake/pr_cmds.c.md)).

**Persistent parameters** (*spawnparms*) — sixteen numbers carried across a level change, hand-packed by the game logic. The whole of
per-player persistence ([`client.qc`](qw-qc/client.qc.md)).

## Networking

**Message** — one protocol unit in a byte stream, identified by a leading kind byte and **not length-prefixed**, so an unknown kind cannot
be skipped ([`protocol.h`](QW/client/protocol.h.md)).

**Reliable stream** — the ordered, guaranteed part of the server-to-client traffic. The original retransmits a message and blocks until it
is acknowledged; QuakeWorld carries it inside ordinary packets with a one-bit acknowledgement
([`net_chan.c`](QW/client/net_chan.c.md)).

**Unreliable payload** — the part that is not retransmitted because the next one supersedes it: the entity snapshot, the player states, the
movement commands.

**Channel** (*netchan*) — QuakeWorld's per-connection record and the functions over it: sequence numbers, the reliable alternating bit, the
byte budget, and the statistics ([`net_chan.c`](QW/client/net_chan.c.md)).

**Connection identifier** (*qport*) — a value the client picks and puts in every packet header, so a connection survives an address
translator rewriting the client's source port. Also what makes the protocol relayable
([`qwfwd.c`](QW/qwfwd/qwfwd.c.md)).

**Byte budget** (*rate* / *cleartime*) — a virtual clock pushed forward by each packet's size times the seconds per byte the link is
assumed to sustain. A leaky bucket. Exhausting it **chokes** a client: its packet is skipped this frame.

**Choked** — a packet not sent because the budget forbade it. Distinct from **lost**, which is a packet the network dropped. Every
diagnostic in QuakeWorld keeps the two apart, because the first means a rate setting is too low and the second means the link is bad.

**Baseline** — an entity's state as captured after the map's spawn functions ran, sent in the level description and used as the delta
reference for an entity that was not in the previous snapshot ([`sv_init.c`](QW/server/sv_init.c.md)).

**Snapshot** (*packet entities*) — one client's view of the visible world at one packet. Kept in a ring on both sides, indexed by packet
sequence, so an update can be a difference from the last one the client **acknowledged**
([`sv_ents.c`](QW/server/sv_ents.c.md), [`cl_ents.c`](QW/client/cl_ents.c.md)).

**Delta reference** (*delta_sequence*) — which remembered snapshot an update is a difference from. The client chooses it and asks for it,
because only the client knows what it still holds.

**Spillover queue** (*backbuf*) — a queue of buffers in front of a client's reliable stream, folded in one per packet, so a burst of
reliable data is spread over frames instead of dropping the player
([`sv_nchan.c`](QW/server/sv_nchan.c.md)).

**Level description** (*signon*) — the reliable block describing a level: the precache lists, the baselines, the static entities. Sent in
several parts because it exceeds one message.

**Level counter** (*spawncount*) — incremented per level change and echoed through every stage of a client's join, so a client that was
mid-join when the level changed is restarted ([`server.h`](QW/server/server.h.md)).

**Zombie connection** — a disconnected client's slot, held for a few seconds so that packets still in flight from the old connection are
not attributed to whoever takes the slot next.

**Challenge** — a random value bound to a requester's address and echoed back in their connection request, proving they can receive at the
address they claim ([`sv_main.c`](QW/server/sv_main.c.md)).

**Information dictionary** (*userinfo* / *serverinfo*) — a single string of separated key-value pairs describing a player or a server.
Unordered, absent-means-default, with a reserved namespace for keys the server asserts itself
([`common.c`](QW/client/common.c.md)). The extensibility mechanism for everything nobody designed in advance.

**Out of band** — a datagram with a distinguished sequence value, handled without any connection. The whole connection and query protocol
is out-of-band text.

**Multicast** — sending a message to the subset of clients that should receive it: everyone, everyone who can see a point, or everyone who
can hear it ([`sv_send.c`](QW/server/sv_send.c.md)).

## Prediction

**Command** (*usercmd*) — one frame's worth of player intent: a duration, view angles, three movement amounts, buttons and an impulse. The
**unit of simulation**: both the client's prediction and the server's authority integrate by the command's duration, not by their own frame
time.

**Movement model** (*pmove*) — player physics as a pure function of a state, a world and a command, extracted so client and server can run
it identically ([`pmove.c`](QW/client/pmove.c.md)).

**Movement world** (*physent list*) — the flat list of at most 32 solid things the movement model collides against, filled by whichever
side is calling ([`pmove.h`](QW/client/pmove.h.md)).

**Movement tunables** (*movevars*) — gravity, friction, accelerations and speed limits, **sent from the server to the client** because a
client predicting with different values diverges on every step.

**Prediction** — replaying every command the server has not yet answered, from the last state it confirmed
([`cl_pred.c`](QW/client/cl_pred.c.md)). Corrections need no explicit reconciliation: the replay simply starts from a newer confirmed
state.

**Extrapolation** — advancing another player forward from their last reported state by running the movement model on their last reported
command. Deliberately **under**-extrapolated, so that corrections read as forward motion rather than a backward jerk
([`cl_ents.c`](QW/client/cl_ents.c.md)).

**Displayed time** — the moment being rendered, set slightly behind the present so there are always two states to interpolate between.

## Memory and platform

**Heap** — the single contiguous block the engine takes from the platform at startup and never returns
([`zone.c`](WinQuake/zone.c.md)).

**Hunk** — the double-ended stack over the heap: allocations from the low end for the session, from the high end for the display, released
only by resetting a mark. Named, so usage can be reported.

**Zone** — the small first-fit heap at the bottom of the hunk, for short strings and small dynamic allocations.

**Cache** — the evictable, least-recently-used store in the gap between the hunk's two ends, for anything reconstructible: models, sounds,
skins. Eviction is silent and a later use reloads.

**Seam** — a boundary where the repo stops and the outside world starts, classified in
[`SYSTEM-REQUIREMENTS.md`](SYSTEM-REQUIREMENTS.md) as **given** (shop for it), **buildable** (the recipe can teach you), or
**pluggable** (the repo owns the interface and ships one filling).

**Tier** — how abstract a language the code can tolerate, on the T0–T4 ladder copied verbatim into
[`SYSTEM-REQUIREMENTS.md`](SYSTEM-REQUIREMENTS.md). The **floor constraint** is the single requirement that stops it moving one step more
abstract.
